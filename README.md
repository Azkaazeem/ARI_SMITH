# Ari Smith - World-Class Illusionist & Mind Reader

An ultra-immersive, cinematic, dark psychological thriller-themed 3D WebGL / MERN web application built for **Ari Smith** (Manchester, UK & International Illusionist).

---

## 🎩 Tech Stack

- **Frontend**: React 18, Vite, TypeScript, Tailwind CSS, Lucide React
- **3D & Graphics**: Three.js (@react-three/fiber, @react-three/drei), custom particle fields, interactive physics
- **Animations**: GSAP + ScrollTrigger, Lenis Smooth Scroll, Framer Motion
- **AI Agent**: Telepathic Assistant / Virtual Concierge with live streaming inquiry handling
- **Audio Ambience**: Web Audio API synthesized psychological thriller soundscapes
- **Backend**: Node.js, Express.js, MongoDB / Mongoose, JWT Authentication
- **Alerts**: SweetAlert2 bespoke dark luxury modals

---

## 🚀 Quick Start

### 1. Backend Server
```bash
cd server
npm install
npm start
```
Runs on `http://localhost:5000` with MongoDB database connection.

### 2. Frontend Client
```bash
cd client
npm install
npm run dev
```
Runs on `http://localhost:3000` with Vite HMR.
